# Projeto Login

Sistema de login desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Login de usuário
- Validação dos campos de login
- Dashboard
- Cadastro de usuários
- Mensagens de erro para campos vazios

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
